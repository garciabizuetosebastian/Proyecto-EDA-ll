Preparando la simulación

Los recuadros rojos son los números comparados; los verdes indican que el arreglo ya quedó ordenado.

Paso: 0 / 0

¿Qué hace el algoritmo?

Compara vecinos. Si el de la izquierda es mayor, los intercambia. Repite hasta ordenar todos.

El código en Python

def bubble_sort(lista):    n = len(lista)    for i in range(n - 1):        for j in range(n - i - 1):            if lista[j] > lista[j + 1]:                lista[j], lista[j + 1] = lista[j + 1], lista[j]    return lista
